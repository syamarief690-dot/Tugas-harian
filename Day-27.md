# Tugas JavaScript Dasar

## Nama
Muhammad Arief Syam

## Deskripsi Tugas

Tugas ini berisi latihan dasar JavaScript. Pada tugas ini saya memperbaiki
kode yang memiliki beberapa error, memperbaiki struktur data, melakukan
perhitungan harga dan pajak, mengenali tipe data, serta menambahkan data
dan perhitungan baru.

## Yang Saya Pelajari

### 1. Memahami Error pada JavaScript

Saya belajar bahwa JavaScript membedakan huruf besar dan kecil pada nama
variabel. Saya juga belajar bahwa kesalahan seperti mendeklarasikan `let`
dua kali atau mengubah nilai `const` dapat menyebabkan program berhenti
dengan error.

### 2. Memahami `let` dan `const`

Saya belajar menggunakan `const` untuk data yang tidak perlu diganti,
sedangkan `let` digunakan jika nilai variabel masih mungkin berubah.
Pemilihan keduanya membuat kode menjadi lebih aman dan mudah dipahami.

### 3. Memahami Object dan Array

Saya belajar bahwa beberapa data yang saling berhubungan lebih baik
disimpan dalam object. Saya juga belajar membuat array yang berisi
beberapa object agar data produk seperti nama dan harga tidak mudah tertukar.

## Hal yang Masih Membingungkan

Hal yang masih sedikit membingungkan bagi saya adalah mengapa
`typeof null` menghasilkan `"object"`, padahal `null` digunakan untuk
menunjukkan bahwa suatu nilai belum memiliki object.

## Kesimpulan

Dari tugas ini saya lebih memahami dasar-dasar JavaScript, terutama
penggunaan variabel, tipe data, object, array, operator, dan struktur
program. Saya juga belajar bahwa membaca pesan error sangat penting untuk
menemukan dan memperbaiki kesalahan dalam kode.

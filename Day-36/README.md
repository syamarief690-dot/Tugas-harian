# Tugas Day 35 — Scope, Hoisting, dan Closure

**Nama:** Muhammad Arief Syam

## Deskripsi
Program latihan JavaScript tentang scope, hoisting, closure, perbaikan kesalahan kode, dan pembuatan program kasir dengan data privat.

## Cara Menjalankan
1. Buka folder `tugas-day-35` di VS Code.
2. Buka terminal di folder tersebut.
3. Jalankan perintah `node tugas_day_35.js`.
4. Periksa hasil program pada terminal.

## Teknologi
- JavaScript
- Node.js
- Visual Studio Code
- Git dan GitHub

## Hal yang Saya Pelajari
Saya belajar bahwa closure dapat menyimpan data privat sehingga data kasir tidak bisa diubah langsung dari luar function.

## Hal yang Masih Membingungkan
Saya masih perlu berlatih memahami perbedaan scope, hoisting, dan closure, terutama saat beberapa variabel memiliki nama yang sama.
